## 4. Evidence quality assessment

**Verified vs inferred labelling — good.** `M1-index.md:84-108` states the grading rule and applies it
consistently: auth/semantics that were never exercised are labelled *inferred* (`/oauth/token`,
`/oauth/revoke`, `/v1/messages`, `/api/web/events`), and existence is separated from semantics. The
discovery document is correctly upgraded to *verified* only because of the provenance fetch at
`M1-anon-probe-matrix.txt:450-469`. The index also deliberately refuses a byte-for-byte claim for the OIDC
body (`:467-468`) and flags the sitemap size deviation (`:408`) rather than hiding it. This is honest
labelling.

**Reproducibility — high.** 19/19 independent requests returned the same status, content type, byte count
and, where captured, the same SHA-256 body hash (robots `e9df3e77…`, sitemap `1c1f5014…`, four JS chunks).
All eight file hashes in `M1-index.md:35-44` recompute exactly against the on-disk files. The chunk-inventory
claim is structurally sound: the 12 root-HTML references and the 12 TSV rows form a perfect bijection.

**Timestamp sanity — mostly good.** Capture timestamps and origin `date` headers are mutually consistent
(e.g. root captured `2026-10-26T05:58:24+08:00` ↔ `date: Sun, 25 Oct 2026 21:58:24 GMT`; the OPTIONS sweep
`22:00:20–22:00:46 GMT` ↔ local `06:00:47+08:00`) and my own probes fall 36 min later at `22:35–22:41 GMT`.
Only the M0 midnight placeholder (D8) is implausible as a measurement.

**Provenance note.** The `HTTP/1.1 200 OK` preamble in the dumps is correctly identified as the proxy CONNECT
handshake (`M1-anon-probe-matrix.txt:39-44`); my own captures show the same artifact, so this is not a hidden
anomaly. All samples under `/tmp` were kept outside `/workspace/re/`.

   (`missing_login`, `unsupported_response_type`, `invalid_platform`); 401-with-bad-token, 403, 429 and any
   `RateLimit-*` headers are undocumented (`M1-index.md:210-212`).
3. **Model identifiers.** `/v1/models` 404s and bundles contain none; must come from an authenticated
   response or vendor docs (`M1-index.md:213-214`).

5. **API-key minting route** — both `create_api_key` paths 404 while `claude_cli/roles` 401s; locate the real
   minting path or confirm removal (`M1-index.md:218-221`).
6. **`/api/download/client` platform vocabulary** and the COS artifact set; `/api/public-assets` (308 target)
   not followed (`M1-index.md:222-226`).
